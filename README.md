# ONI Custom Simulation API: preview (archived)

**This preview has been replaced by the released SDK.** The repository is kept read-only so
that old links still lead somewhere. Nothing here is maintained.

## Where to go now

- **Start here:** [oni-sdk-docs](https://github.com/Salacious-Oni-Dev/oni-sdk-docs): what the SDK is, how to install and
  remove it, and where a mod author starts.
- **Releases** (v0.1.0-alpha.1, an alpha, Windows only):
  [simulation library](https://github.com/Salacious-Oni-Dev/oni-sim-replacement/releases/tag/v0.1.0-alpha.1) ·
  [framework](https://github.com/Salacious-Oni-Dev/oni-framework-api/releases/tag/v0.1.0-alpha.1) ·
  [flagship mods](https://github.com/Salacious-Oni-Dev/oni-flagship-mods/releases/tag/v0.1.0-alpha.1)

| Repository | What it is |
|---|---|
| [oni-sim-replacement](https://github.com/Salacious-Oni-Dev/oni-sim-replacement) | The simulation library that replaces the game's `SimDLL.dll`, and its extension API |
| [oni-framework-api](https://github.com/Salacious-Oni-Dev/oni-framework-api) | The managed API that mods call |
| [oni-flagship-mods](https://github.com/Salacious-Oni-Dev/oni-flagship-mods) | Gameplay mods built on the SDK |
| [oni-sim-visualizer](https://github.com/Salacious-Oni-Dev/oni-sim-visualizer) | A standalone visualizer and debugger for the simulation |
| [oni-dev-environment](https://github.com/Salacious-Oni-Dev/oni-dev-environment) | A debuggable development copy of the game |
| [oni-sdk-docs](https://github.com/Salacious-Oni-Dev/oni-sdk-docs) | Guides for the SDK as a whole |

The API pages that used to be in `docs/api/` now point to their current references.
